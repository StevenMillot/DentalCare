4 · Plan d’action priorisé

P1 — Impact immédiat
  • Parodontiste + local (Châtenay-Malabry / 92) en title, H1, intro
  • Implant dentaire (singulier) + local
  • Cône beam / Cone beam jumelé à CBCT
  • Symptômes paro : déchaussement, saignements, dents qui bougent
P2 — Renforcement actes
  • Greffe osseuse / pré-implantaire (H2 + meta)
  • Surfaçage radiculaire dans le protocole
  • Greffe sinusienne / sinus lift + lien CBCT
  • Avulsion en synonyme sur extractions
P3 — Finitions
  • Parodontologue / implantologue (mentions naturelles)
  • Chirurgie des gencives / muco-gingivale
  • Chirurgie buccale : une mention historique max
  • Frénectomie dans le title de la page frein

5 · Règles d’intégration (anti-bourrage)

À faire

  • 1 intention principale par URL (silos déjà bien structurés)
  • Synonymes dans le 1er écran + 1 H2, pas une liste keyword
  • Toujours coupler acte + localité sur les pages business
  • Langage patient en intro, jargon pro en corps / FAQ
  • E-E-A-T : signatures praticiens, formations, photos cliniques

À éviter

  • Répéter les 30 termes sur l’accueil
  • Créer des pages fines pour chaque orthographe
  • Affirmer des titres non reconnus par l’Ordre
  • Cibler des techniques non proposées
  • Confondre densité de mots-clés et pertinence médicale

Méthodologie & sources

  • Inventaire : comptage sur le HTML public du dépôt (contenu, meta, JSON-LD, formulaires).
  • Cadre SEO dentaire : prioriser intention commerciale locale et actes à forte valeur (implantologie, parodontie).
  • Synonymie clinique : parodontie = parodontologie ; parodontiste ≈ parodontologue (usages santé grand public FR).
  • Nomenclature FR : chirurgie orale = spécialité actuelle (CNPCO / Ordre) ; remplace stomatologie / chirurgie buccale.
  • Imagerie / extractions : CBCT / Cone Beam utilisés indifféremment ; « avulsion » est le terme technique HAS.
  • Limite : pas d’export Keyword Planner / Ahrefs — priorités relatives, pas volumes mensuels absolus.
